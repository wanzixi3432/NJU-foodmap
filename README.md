# 南大人的美食地图

地图浏览版网站。游客可以浏览店铺和地图；注册并登录后可以评分、上传图片、发布评价，并查看其他登录用户的评价。

## 打开方式

双击 `start.cmd`，或者直接打开 `index.html`。

如果需要在不同设备间单独发送，请使用 `南大人的美食地图-单文件版.html`。该文件不需要随附 `data/` 或 `vendor/` 文件夹。

同一 Wi-Fi 下让手机或另一台电脑访问时，双击 `start-server.cmd`，使用命令行窗口中显示的局域网网址。

发送到不同网络时，可以把 `nju-food-map-static.zip` 解压后上传到 Netlify Drop、Cloudflare Pages、GitHub Pages 等静态托管平台。

登录、评价和图片需要 Supabase 云端服务。首次发布请按照 `SUPABASE-SETUP.md` 完成配置，否则地图可以浏览，但登录和评价会显示“云端服务尚未配置”。

## 数据来源

- 店铺名单和作者评语来自用户提供的 `南京鼓楼美食（修正） (1).docx`。
- 第二份图片攻略中新增的店铺按名称去重合并，并标记为“攻略图补充”。
- 百度地图仅用于补充店铺地址和坐标，百度评分不展示，也不参与综合评分。
- 知名连锁分店按南京大学鼓楼校区 2km、仙林校区 3km 筛选并去重。
- 美团和大众点评没有开放公开评分接口，因此详情页提供平台搜索入口；未取得可靠平台评分的店铺标记为“待平台核验”。

## 页面内容

- 共 514 家店铺，其中原有整理店铺 281 家、知名连锁分店 233 家。
- 连锁部分覆盖 38 个品牌：鼓楼校区 2km 内 188 家，仙林校区 3km 内 45 家。
- 支持店铺搜索、菜系筛选、红榜筛选、校区范围筛选和距离排序。
- 地图点位、完整街道边界、主要道路与校区半径圈展示。
- 综合评分规则：有用户评分时为 `0.2×美团 + 0.2×大众点评 + 0.6×用户`；无用户评分时为 `0.5×美团 + 0.5×大众点评`。
- 平台评分缺失或尚未核验时不会编造分数。
- 每位用户对同一家店保留一条可更新评价；评价包含 1–5 分、文字和最多 6 张图片。
- 登录用户可以看到其他用户发布的评价和图片，用户均分按 60% 权重加入综合评分。
- 在线底图使用国内网络通常可访问的高德地图；底图不可用时仍显示内置道路和街道边界。
- 美团、大众点评及百度地图跳转。
- 桌面与手机响应式布局。
