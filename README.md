# 南大人的美食地图

静态只读版网站。保留左侧店铺列表和右侧南京地图布局，不提供用户录入、评价或编辑权限。

## 打开方式

双击 `start.cmd`，或者直接打开 `index.html`。

同一 Wi-Fi 下让手机或另一台电脑访问时，双击 `start-server.cmd`，使用命令行窗口中显示的局域网网址。

发送到不同网络时，可以把 `nju-food-map-static.zip` 上传到 Netlify Drop、Cloudflare Pages、GitHub Pages 等静态托管平台。

## 数据来源

- 店铺名单和作者评语来自用户提供的 `南京鼓楼美食（修正） (1).docx`。
- 第二份图片攻略中新增的店铺按名称去重合并，并标记为“攻略图补充”。
- 店铺地址、地图坐标和百度地图评分通过百度地图移动端搜索结果补充。
- 找不到可靠匹配的店铺仍会保留在列表中，并标记为“待定位”；详情中提供百度地图搜索入口。
- 美团和大众点评没有开放公开评分接口，因此详情页提供平台搜索入口，评分与评价以平台页面显示为准。

## 页面功能

- 合并整理文档与图片攻略后，共 229 家去重店铺。
- 原文档红榜推荐标记。
- 店铺搜索、菜系筛选、红榜筛选、鼓楼校区 2km 筛选和距离排序。
- 百度评分和地图点位展示。
- 美团、大众点评及百度地图跳转。
- 桌面与手机响应式布局。
