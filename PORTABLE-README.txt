南大人的美食地图（地图浏览与共享评价版）

一、在本机打开
双击 index.html，或双击 start.cmd。

如果只需要发送一个文件，请发送“南大人的美食地图-单文件版.html”。
它已经包含全部店铺、地图边界、连锁分店数据和程序文件，无需同时发送其他文件夹。

二、复制到其他电脑
复制整个网站文件夹到另一台电脑，双击 index.html 即可浏览。
网站不依赖 Python、数据库或后端服务，但高德地图在线底图需要联网。
离线道路、街道边界、店铺名称、地址和坐标已经打包在网站内。

三、同一 Wi-Fi 下用手机访问
1. 确保电脑和手机连接同一个 Wi-Fi。
2. 双击 start-server.cmd。
3. 在命令行窗口中找到“同一 Wi-Fi 手机/电脑访问地址”，例如：
   http://192.168.1.20:4173
4. 把这个地址输入手机浏览器。
如果无法打开，请在 Windows 防火墙提示中允许 Node.js 访问专用网络。

四、发给不同网络的人
需要把整个网站上传到公网静态托管平台，例如：
- Netlify Drop
- Cloudflare Pages
- GitHub Pages
上传后即可得到公共网址。GitHub Pages 建议直接使用 github-pages/index.html 作为首页。
登录用户可以为店铺评分、上传图片、发布评价并查看其他用户的评价。
跨网络共享依赖 Supabase。首次部署请阅读 SUPABASE-SETUP.md，并把
Project URL 和 anon public key 填入 cloud-config.js。

店铺与评分说明
- 共 514 家店铺，其中知名连锁分店 233 家，覆盖 38 个品牌。
- 连锁分店仅保留南京大学鼓楼校区 2km 与仙林校区 3km 内的结果。
- 百度地图仅用于地址和定位，百度评分不展示且不参与计算。
- 未取得可靠美团、大众点评评分的店铺显示“待平台核验”。
- 每位用户对同一家店保留一条评价，再次提交时会更新原评价。
- 每条评价最多上传 6 张图片；手机原图会在浏览器中自动压缩。
